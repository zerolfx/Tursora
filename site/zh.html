内置工具

内置终端和 ZIP 浏览

默认启用终端入口和 ZIP 浏览，可在 Tursora → Settings… 中关闭；已有设置会保留。

0.3.0 新增

多选后可按 Finder 的替换文本、添加文本与格式三种模式批量重命名，并实时预览。废纸篓可以像普通文件夹一样浏览，放回 Tursora 移入的项目，或直接清倒。终端与文件视图双向跟随目录，支持 zsh、bash 与 fish。排序与列表列新增创建日期、添加日期与最后打开日期，文件夹可显示条目数。拖拽悬停可自动展开文件夹，可投放到路径栏，按住 Command 强制移动。Shift-Command-O 打开命令面板，搜索全部命令、收藏与最近目录。

0.2.1 终端改进 F4

通过工具栏按钮或 F4 展开、收起终端，标题栏更紧凑；收起后会话继续运行。默认 zsh 会话跟随当前浏览窗格的目录，隐藏时也会同步。前台命令执行期间、read 正等待输入或命令尚未输入完时，会暂缓切换目录。其他自定义 Shell 使用 Restart 手动打开当前浏览目录。Shell、字体、配色和快捷键仍可设置；退出、关窗或重启 Shell 前，检测到任务会先确认。

把 ZIP 当作只读目录浏览

打开过程中可以取消，失败后可以重试或返回所在文件夹。仅支持普通 ZIP。打开的临时副本会在应用退出时清理；需要保留编辑，请在外部应用中“另存为”。不支持密码 ZIP 或直接写回归档。

通过 DMG 安装

{{VERSION}} 已发布，提供 Apple Silicon 的 DMG 安装包。

  1. 在最新正式版本下载 Tursora-{{VERSION}}-macOS-arm64.dmg；同页提供 SHA-256 校验文件，无需 GitHub 账号。
  2. 双击打开 DMG。
  3. 将 Tursora.app 复制到可写入的目录：/Applications、~/Applications 或其他位置均可。
  4. 打开复制后的应用，不要直接在只读 DMG 内运行。

首次打开：按实际路径处理

若 macOS 无法验证应用，确认官方来源并核对同版本 SHA-256 后，在终端执行以下命令；把路径换成实际安装位置：

xattr -dr com.apple.quarantine "/Applications/Tursora.app"

不想手输路径？输入 xattr -dr com.apple.quarantine 和一个空格，将安装后的应用拖入终端，再按回车，然后打开应用。对自己拥有且可写入的副本，通常无需管理员密码。个人目录可用 "$HOME/Applications/Tursora.app"；组织管理的设备仍可能需要 IT 批准。首次启动与权限说明

通过 Homebrew 安装

按顺序执行以下三条命令：添加仓库、信任 Tursora 安装定义、安装应用。每条成功后再继续，保留第一条的完整仓库 URL：

brew tap zerolfx/tursora https://github.com/zerolfx/Tursora
brew trust --cask zerolfx/tursora/tursora
brew install --cask zerolfx/tursora/tursora

若报错提示找不到 zerolfx/homebrew-tursora，Homebrew 使用了默认 tap 地址。请先完整执行上方含 URL 的第一条命令。Tap 安装已发布的 {{VERSION}} DMG，并校验固定 SHA-256。更新与卸载说明 ↗

第二条只信任 Tursora 的安装定义。若仍提示 untrusted tap，见安装排错说明。

指定其他目录，可在第三条加上 --appdir="$HOME/Applications"，或替换为所需目录。若 Homebrew 自身的目录没有写入权限，直接用 DMG 安装即可。首次启动仍按上方步骤处理。

让 agent 帮你安装
