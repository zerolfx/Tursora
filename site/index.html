右下角 Terminal 显示运行、隐藏或结束状态及任务数，点击即可展开或收起；首次展开才启动 Shell。工具栏按钮、F4 或面板关闭按钮只收起终端，再展开继续原会话；设置中关闭入口也保留会话。可选 Shell、等宽字体和配色，快捷键也能自定义。退出、关窗或重启前，检测到任务会先确认。

把 ZIP 当作只读目录浏览

打开过程中可以取消，失败后可以重试或返回所在文件夹。仅支持普通 ZIP。打开的临时副本会在应用退出时清理；需要保留编辑，请在外部应用中“另存为”。不支持密码 ZIP 或直接写回归档。

通过 DMG 安装

0.2.0 已发布，提供 Apple Silicon 的 DMG 安装包。

  1. 在最新正式版本下载 Tursora-0.2.0-macOS-arm64.dmg；同页提供 SHA-256 校验文件，无需 GitHub 账号。
  2. 双击打开 DMG。
  3. 把 Tursora 拖到 Applications。
  4. 从“应用程序”打开 Tursora。

若系统无法验证此应用，确认官方来源及下载可信后，可在“系统设置 → 隐私与安全性”中选择“仍要打开”，再确认打开。详见首次启动说明。0.1.0 用户需手动升级一次，才能使用应用内更新。

通过 Homebrew 安装

在终端执行以下两条命令：

brew tap zerolfx/tursora https://github.com/zerolfx/Tursora
brew install --cask zerolfx/tursora/tursora

Tap 安装已发布的 0.2.0 DMG，并校验固定 SHA-256。更新与卸载说明 ↗
