# Application icon

Tursora's mark combines two blue glass panes into an abstract dolphin tail fin. The artwork uses a single continuous pale background, with no inset tile or pre-rendered outer rounded-square border. It is a static raster design inspired by the current macOS glass aesthetic, not a layered Icon Composer asset.

The foreground spans approximately 67% of the canvas width, leaving room for the system's rounded corners. Only the foreground was reduced; the pale background remains full bleed.

- `AppIcon-artwork.png`: final composition edit from the built-in image generation tool.
- `AppIcon.png`: full-bleed 1024px master, resized from the generated original.
- `icon-prompt.txt`: original generation prompt and final spacing-edit prompt.
- `AppIcon.icns`: 16–1024px icon family, generated by `app/tools/make-icon.sh`.
- `app/tools/make-app.sh`: embeds the family and registers `CFBundleIconFile`.

The full-bleed background avoids baking an extra backplate into a smaller icon within the system's rounded icon treatment. See [Apple's app icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons). The smoke test checks dimensions, opaque corners, and icon-family sizes. Actual Dock appearance also requires visual inspection after packaging.

The spacing edit was checked in the packaged 0.1.0 (4) About panel using computer use: the mark sits comfortably inside the system-rounded icon with one background. All 618 smoke checks passed three consecutive runs; the packaged ICNS matches the source and the app signature verifies.
